# FINDaero CHANGELOG

The aviation industry, change by change.

Стартовая версия FINDaero CHANGELOG с отдельными переходами и рабочими пространствами для ленты, флота, ливрей, маршрутов, сравнения и реестра источников. Реальных записей пока нет: карта маршрутов и хронологии намеренно остаются пустыми до подключения проверяемых данных.

Проект настроен на публикацию статического сайта через GitHub Pages. Workflow `.github/workflows/webpack.yml` автоматически собирает сайт после каждого push в ветку `main`.

## Запуск

Нужен Node.js 18.17 или новее.

```bash
npm install
npm run dev
```

Затем открыть http://localhost:3000. Production-сборка создаётся командой `npm run build` в папке `out`.

## Статус

Это статическая UI-версия. Общие доменные типы событий, статусы проверки, источники, модерация, ливреи, импорт и сущности находятся в `lib/domain.ts`; проекция координат и построение дуг маршрутов — в `lib/route-map.ts`. PostgreSQL/Prisma, серверный API, админ-аутентификация, модерация, адаптеры источников и ежедневный импорт ещё не реализованы. GitHub Pages сможет показывать интерфейс; для сервера и базы данных понадобится отдельный хостинг. Публичная лента должна принимать только подтверждённые события с источниками.

## Загрузка в GitHub через браузер

1. Создать репозиторий на GitHub и загрузить в него содержимое распакованного ZIP (не сам ZIP).
2. В репозитории открыть **Settings → Pages** и выбрать **GitHub Actions** в разделе Build and deployment.
3. Открыть вкладку **Actions**. Workflow развернёт сайт; адрес появится в результате запуска и в Settings → Pages.
4. Для автоматической публикации последующих изменений загружать их в ветку `main`.
5. Не добавлять `.env` и секреты. Файл `.env.example` безопасен для публикации.

Если репозиторий называется `имя.github.io`, GitHub Pages может публиковать его в корне домена. В текущей настройке используется адрес проекта `https://имя-пользователя.github.io/имя-репозитория/`.

Если GitHub предложит загрузить архив целиком, не загружайте ZIP как единственный файл: распакуйте его и загрузите файлы проекта, чтобы GitHub показывал исходный код.
