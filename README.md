# FINDaero CHANGELOG

The aviation industry, change by change.

Стартовый интерфейс сервиса для хроники изменений российской гражданской авиации. В текущей версии реализованы адаптивная оболочка, разделы CHANGELOG / FLEET / LIVERIES / ROUTES / COMPARE / SOURCES, поиск и фильтры интерфейса. Реальных записей пока нет: приложение намеренно показывает пустое состояние и не выдумывает события или подключения источников.

## Запуск

Нужен Node.js 18.17 или новее.

```bash
npm install
npm run dev
```

Затем открыть http://localhost:3000. Для production-сборки: `npm run build`, затем `npm start`.

## Статус

Это первая UI-основа, а не завершённая система мониторинга. База данных, админ-аутентификация, хранение и модерация событий, реальные адаптеры источников и ежедневный импорт ещё не реализованы. Следующие этапы описаны в исходном задании. Публичная лента должна принимать только подтверждённые события с источниками.

## Загрузка в GitHub через браузер

1. Создать пустой репозиторий на GitHub.
2. Скачать ZIP, распаковать его.
3. На странице репозитория выбрать **Add file → Upload files** и перетащить содержимое распакованной папки.
4. Не добавлять `.env` и секреты. Файл `.env.example` безопасен для публикации.

Если GitHub предложит загрузить архив целиком, не загружайте ZIP как единственный файл: распакуйте его и загрузите файлы проекта, чтобы GitHub показывал исходный код.
